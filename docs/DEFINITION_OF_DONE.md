# Definition of Done

A task (user story) is **done** only when all of these are true:

1. **It works** — the code runs and does what the story asked.
2. **It is tested** — you tried it yourself (for detection, using `tools/fake_ransomware.py`) and it behaves correctly.
3. **It is peer-checked** — at least one teammate reviewed it via a Pull Request before it was merged into `main`.
4. **It is saved** — committed and pushed to GitHub on a feature branch, then merged.
5. **It is integrated** — it works together with the other parts, not only on its own.
6. **It is shown** — demonstrated to the teacher (Gayatri) at the sprint review.

If any point is missing, the task stays **in progress**.
